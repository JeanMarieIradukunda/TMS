Session Plan Generator

Pick a module, a learning outcome and the number of teaching periods — this page drafts a complete, print-ready session plan in the standard competence-based training format: session information, facilitation techniques, a fully staged introduction / development / conclusion, and evaluation & reflection sections.

1. Choose module, outcome & session details

The learning outcome list narrows down automatically once you pick a module. Duration is calculated from the number of periods you choose.

No modules have been set up in the system yet. Please ask an administrator to add trades, modules and learning outcomes before a session plan can be generated.

Each period must be 40 or 50 minutes. Time is distributed automatically across the introduction, development and conclusion — you can fine-tune every duration afterwards.
